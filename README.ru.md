# ChatGPT Ads Product Feed для OpenCart 3

Расширение для OpenCart 3.0.x. Выгружает каталог в фид товаров в [формате OpenAI](https://developers.openai.com/commerce/specs/file-upload/products) для кампаний **ChatGPT Ads**. В Ads Manager нужно вставить одну ссылку (**Hosted URL**), дальше фид обновляется сам, без cron и дополнительной настройки.

[English version](README.md)

## Возможности

- **Все обязательные поля OpenAI:** `item_id`, `title`, `description`, `url`, `brand`, `seller_name`, `image_url`, `price`, `availability`, `target_countries`, `store_country`.
- **Рекомендуемые поля:** акционная цена `sale_price` (из акций OpenCart), дополнительные фото, категория, `gtin` (EAN/UPC/JAN/ISBN), `mpn`, вес, доставка, возвраты, ссылки на политики, `is_ads_eligible`.
- **Метки `ads_metadata` для группировки в Ads Manager:**
  - `custom_label_0` — верхняя категория;
  - `custom_label_1` — `on_sale` для товаров с акцией;
  - `custom_label_2` — бренд.
- **Варианты из опций.** Вы выбираете опции, например «Цвет» или «Объём». Каждое значение или сочетание значений становится отдельной строкой с `group_id`, `listing_has_variations` и `variant_dict`. Учитываются надбавки к цене и остатки опций.
- **Статическая ссылка:** `https://ваш-сайт/chatgpt-feed/КЛЮЧ.csv`. Ads Manager не принимает ссылки с параметрами.
- **Обновляется сам.** Когда фид устаревает, обычные заходы покупателей запускают пересборку в фоне, cron не нужен.
- **Большие каталоги.** Сборка идёт частями по 200 товаров и укладывается в лимит времени PHP: если не успела, продолжает в новом запросе. Память не растёт.
- **WebP и GIF** один раз переводятся в JPEG и кэшируются в `image/cache/chatgpt-feed/`, потому что OpenAI принимает только JPEG и PNG.
- **Проверка перед выгрузкой.** Товары без обязательных полей, со ссылками не по HTTPS, неподходящими картинками или нулевой ценой пропускаются. Причины видны в админке и в логе.
- **Delta API (необязательно).** При сохранении товара в админке его цена и наличие сразу отправляются в ChatGPT Ads.
- Формат на выбор: CSV, TSV или JSONL.

## Требования

- OpenCart 3.0.x (проверено на 3.0.4.2)
- PHP 7.0+ с расширениями cURL и GD (для WebP нужна поддержка WebP в GD)
- сайт на HTTPS
- PHP может писать в корень сайта (`chatgpt-feed/`) или в `image/`

## Установка

1. Скачайте `oaiq_chatgpt_feed.ocmod.zip` из [Releases](../../releases) или соберите архив командой `python build.py`.
2. Откройте **Расширения → Установка расширений** и загрузите архив.
3. Откройте **Расширения → Расширения**, выберите тип **Фиды**, найдите **ChatGPT Ads Product Feed**, нажмите **Установить**, затем **Редактировать**.
4. Заполните настройки:
   - **Status** — включите;
   - страна магазина, целевые страны и валюта, например `UA` / `UA` / `UAH`;
   - название продавца;
   - ссылки на политики, полностью, с `https://`.

   Нажмите **Сохранить**.
5. Нажмите **Rebuild now** и дождитесь «Done».
6. Скопируйте **Hosted feed URL**. В ChatGPT Ads Manager откройте фид, нажмите на три точки, выберите **Hosted URL** и вставьте ссылку.

Обновление: загрузите новый архив поверх старого и один раз нажмите **Сохранить** на странице модуля.

## Безопасность

- Ссылка на фид и ссылка для cron защищены случайным ключом из 32 символов. У Delta API отдельный секрет из 64 символов.
- Принудительная пересборка возможна не чаще раза в 5 минут, две сборки одновременно не запускаются.
- Все настройки проверяются при сохранении. API-ключ не показывается в браузере, вывод в админке экранируется.
- Файлы ядра OpenCart не меняются, модуль работает только через события.
